# Heart Disease Prediction

This project uses supervised learning to predict whether a patient has heart disease based on medical features.

## Goal
The goal is to determine if we can identify patients at risk using machine learning.

## Dataset
Heart disease dataset from Kaggle with features like age, cholesterol, and blood pressure.

## Model
Decision Tree Classifier (classification problem)

## Files
- heart_model.ipynb → main notebook
- heart.csv → dataset
